# SQL 
- ### SQL (Structured Query Language) is a standard language used to manage relational databases.


<br/>

# SQL DBMS(s)

## An SQL DBMS is a relational database system that:
- ### Uses SQL as its query language
- ### Stores data in tables
- ### Maintains relationships
- ### Ensures integrity and consistency
- ### Supports transactions 
- ### Example - PostgreSQL, MySQL, Oracle Database, Microsoft SQL Server, etc
